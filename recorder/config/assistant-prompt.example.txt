會議助理提示詞（常駐領域背景 · 範本）
======================================
這是「會議助理提示詞」的範本。複製成同目錄的 assistant-prompt.txt 後填入你的領域背景。
此檔內容會在「重新摘要 / 再加工 / 校稿」時注入 LLM，用來理解術語、還原專有名詞、框定重點方向。
跨會議通用（不綁單一場次）；單場專屬的主題請改用每份記錄的「前情提要（## 會議背景）」。

填寫建議（依自身領域改寫，下面只是格式示意、非實際內容）：
- 角色：本系列會議多為 <某領域> 的 <設計 / 評審 / 同步> 會議。
- 常見術語 / 專有名詞：<列出領域術語、模組名、產品名、人名，協助 STT 同音錯字校正>。
- 常見參與方 / 角色：<例 產品 / 後端 / 設計 / 測試 / 法務>。
- 重點關注：<希望摘要優先抽出的面向，例 決議 / 風險 / 待辦負責人 / 時程>。
