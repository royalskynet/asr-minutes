# 熱詞清單（範本）— 一行一詞，提升 STT 對領域專有名詞的辨識
#
# 用法：複製成同目錄 hotwords.txt，每行一個詞（公司名 / 人名 / 產品名 / 技術術語）。
# 啟用後 STT 改用 modified_beam_search 解碼並偏置這些詞；檔案不存在則維持預設 greedy。
# 注意：此模型（zipformer 雙語 zh-en）對中文以「字」為單位，若效果不佳，
#       可把中文詞拆成空白分隔的單字（例：專 案 代 號）。需在實機錄製驗證。
# 以 # 開頭或空行會被忽略。
#
# 範例（請刪除並換成你自己的詞）：
# 某產品名
# 某模組代號
# 某專有名詞
